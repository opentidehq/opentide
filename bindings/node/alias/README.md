# opentide

An alias of [`@opentide/opentide`](https://www.npmjs.com/package/@opentide/opentide), the
[opentide](https://opentide.org) SDK and command line for Node.js, so that `npx opentide` works.
It depends on `@opentide/opentide` at the same version and re-exports it; its `opentide` command
is that package's.

Documentation: [opentide.org/docs/sdk/typescript](https://opentide.org/docs/sdk/typescript).
