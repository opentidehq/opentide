# opentide-ecs — agent guide

The Elastic Common Schema field catalog for the Elastic engines (ES|QL, EQL, kuery, Lucene):
completion, hover, the ECS-index test (`indices_are_ecs`) and the type and near-miss checks the
engines share.

## Place

foundation, tier 1: depends on opentide-core. Used by opentide-kuery, -lucene, -esql, -eql,
-tide and -analysis.

## Invariants

- `data/catalogs/ecs/fields.json` is generated by `scripts/engine/sync_ecs_fields.py` from a tagged `elastic/ecs` release (Apache-2.0, `data/catalogs/ecs/NOTICE`). Regenerate, never hand-edit.
- The field list is never closed: an unknown field is not an error. Only a known field's type is checked, and only where Elasticsearch rejects the query.
- No `std::fs` in `src/`; the catalog loads once (`OnceLock`).

## Test

```bash
cargo nextest run --profile fast -p opentide-ecs
```

The engines' ECS checks are exercised by `opentide-analysis`'s `ecs_fields` and
`live_elasticsearch_probes` tests.

## Do not

- Turn an unknown field into an error.
