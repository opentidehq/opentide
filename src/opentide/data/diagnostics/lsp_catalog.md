# lsp_catalog

The workspace has the language server's catalogs, generated by this version of opentide.

Reported by `opentide doctor`. `opentide generate schemas` writes `.opentide/lsp/catalogs/generated/fields.json` and `deprecations.json` from the workspace's schemas; `opentide lsp start`, `opentide lsp check` and editors use them, and the catalog compiled into the engine when they are missing. Warns when they are missing, do not parse, or come from another opentide version.

## Example

```text
! No language-server catalog in .opentide/lsp/catalogs/generated: the editor and lsp check use the bundled one, which does not know this workspace's vocabulary · lsp_catalog
  → opentide generate schemas
```

## How to fix

Run `opentide generate schemas` (or `opentide generate`) and commit the files it writes, so every editor on the repository uses the same catalog.
