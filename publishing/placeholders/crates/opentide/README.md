# opentide (reserved)

This name is reserved for the opentide Rust SDK. Version 0.0.0 has no API.

[opentide](https://opentide.org) is spec-driven development for agentic detection engineering: it validates, indexes, deploys and documents detection-as-code across nine security platforms. Today it ships as the Python package [`opentide`](https://pypi.org/project/opentide/):

```bash
pip install opentide
```

The SDK will be this crate, the one public API of the opentide Rust core, built in [opentidehq/opentide](https://github.com/opentidehq/opentide) ([#790](https://github.com/opentidehq/opentide/issues/790)).
