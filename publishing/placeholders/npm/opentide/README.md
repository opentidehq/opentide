# opentide (reserved)

This name is reserved for an alias of [`@opentide/opentide`](https://www.npmjs.com/package/@opentide/opentide), the opentide TypeScript SDK and CLI. Version 0.0.0 has no code.

[opentide](https://opentide.org) is spec-driven development for agentic detection engineering: it validates, indexes, deploys and documents detection-as-code across nine security platforms. Today it ships as the Python package [`opentide`](https://pypi.org/project/opentide/):

```bash
pip install opentide
```

`@opentide/opentide` will be built from the opentide Rust core in [opentidehq/opentide](https://github.com/opentidehq/opentide) ([#790](https://github.com/opentidehq/opentide/issues/790)).
