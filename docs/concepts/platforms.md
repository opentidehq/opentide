# Platforms

OpenTide supports **7 deployment platforms** and **5 query validators**.

| Platform | Deploy | Query validate |
|----------|--------|----------------|
| Microsoft Sentinel | yes | yes |
| Defender for Endpoint | yes | yes |
| Splunk | yes | yes |
| SentinelOne | yes | yes |
| Carbon Black Cloud | yes | yes |
| CrowdStrike Falcon | yes | no |
| HarfangLab | yes | no |

Use `opentide info` or the `opentide://platforms` MCP resource to inspect capabilities at runtime.
