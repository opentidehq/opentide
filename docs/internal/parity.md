# Parity dashboard

> Generated by `cargo xtask parity dashboard` (UC-X.2, [#844](https://github.com/opentidehq/opentide/issues/844)); the `parity` workflow renders it on every pull request and push and, when a maintainer enables it, commits it to the branch.
