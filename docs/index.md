# OpenTide

OpenTide is the DetectionOps engine for detection-as-code repositories.

## Install

```bash
pip install "opentide[sentinel,cli]>=0.1"
```

## Quick commands

```bash
opentide validate
opentide generate
opentide deploy --platform sentinel --dry-run
```

See the [migration guide](getting-started/migration.md) for submodule → package upgrades.
